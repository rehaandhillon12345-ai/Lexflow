# LexFlow ⚖️

A modern legal client onboarding dashboard built using React.js and Vite.  
LexFlow helps law firms manage clients, track case progress, organize legal documents, and monitor onboarding workflows through a clean and professional interface.

---
## 🌐 Live Demo

"https://lex-flow-kappa.vercel.app/"

## 🚀 Features

### 🔐 Login Interface
- Clean professional login page
- Smooth onboarding experience
- Frontend-only authentication flow

### 📊 Dashboard
- Total clients overview
- Active cases tracking
- Pending documents monitoring
- Closed cases statistics
- Recent activity feed
- Case completion progress section
- Live legal news integration using API

### 👥 Clients Management
- Dynamic client table
- Search functionality
- Case type display
- Status badges with colors
- Responsive table layout

### 📁 Case Details
- Detailed client information
- Uploaded documents section
- Pending documents section
- Interactive case timeline
- Clean card-based UI

### 📰 Legal News API
- Real-time legal news integration
- Dynamic API fetching using `fetch()` and `useEffect`
- Makes dashboard feel realistic and live

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/sameersharma06/lexflow.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd lexflow
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Setup Environment Variables

Create a `.env` file in the root directory.

```env
VITE_NEWS_API_KEY=YOUR_API_KEY
```

---

## 5️⃣ Start Development Server

```bash
npm run dev
```

Open the Vite local server URL in your browser.

---

# 🏗️ Build Project

```bash
npm run build
```

# 🎯 Project Objective

LexFlow was developed as an academic frontend project to demonstrate:
- modern dashboard UI design
- reusable React components
- state management using hooks
- API integration
- responsive layouts
- real-world problem solving

The project focuses on improving legal client onboarding workflows by replacing manual communication methods with a centralized dashboard system.
